# PEACE2074 tvOS

This folder contains a standalone native SwiftUI tvOS app that sits beside the existing NativeScript mobile app.

## Open in Xcode

Open:

- `peace2074-tvOS/peace2074-tvOS.xcodeproj`

## Run

1. Select the `peace2074TV` scheme.
2. Choose an Apple TV simulator.
3. Build and run.

## Notes

- Bundle identifier default: `com.peace2074.tvos`
- Deployment target: tvOS 17.0
- The app is intentionally small and native-first so we can grow it independently from the iOS NativeScript runtime.
